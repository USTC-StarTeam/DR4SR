1. Paper

Mingjia Yin, Hao Wang, Wei Guo, Yong Liu, Suojuan Zhang, Sirui Zhao, Defu Lian, and Enhong Chen. Dataset Regeneration for Sequential Recommendation. In Proceedings of KDD 2024, pages 3954-3965, 2024.

DR4SR regenerates training sequences to improve data quality for sequential recommendation and received the KDD 2024 Best Student Paper award.

3. Quick Start

DATASET=amazon-toys
DATA_ALIAS=toy
ROOT_PATH=./dataset/${DATASET}/${DATA_ALIAS}/
python 1.Build_pretraining_dataset.py --root_path $ROOT_PATH
python run.py --model SASRec --dataset $DATASET
python 2.Pretrain_regenerator.py --root_path $ROOT_PATH --K 5
python 3.Hybrid_inference.py --root_path $ROOT_PATH
python run.py -m SASRec -d amazon-toys
